# TIMEPRICE

**Твои деньги. Твоё время. Твой выбор.**

TIMEPRICE — офлайн-приложение для Android, которое переводит стоимость покупок
в рабочее время: часы и рабочие дни. Сделано на Godot 4.x (GDScript, Control-узлы).

Приложение не оценивает покупки. Оно показывает объективные цифры, чтобы
решение принимал сам пользователь. Без регистрации, рекламы, внешних API и
банковских интеграций. Все данные хранятся только на устройстве.

## Финансовая точность

- Суммы хранятся в `int` в минимальных единицах (тиын/копейка/цент): `350 000 ₸` → `35000000`.
- Длительность рабочего дня хранится в минутах (`7,5 ч` → `450`).
- В `FinancialCalculator` целочисленные произведения считаются точно,
  а деление выполняется один раз в конце. Округление происходит только при отображении (`Fmt`).
- Деление на ноль невозможно: некорректный профиль или цена возвращают нулевой
  результат или код ошибки.
- Пределы (до 10¹² основных единиц) гарантируют отсутствие переполнения int64.

## Сохранение данных

- `user://timeprice_data.json` — профиль, история, цели и желания (`schema_version` = 3;
  файлы версии 1 читаются без потерь, цели и желания начинаются с пустых списков).
- `user://timeprice_data.backup.json` — предыдущая версия файла.
- `user://settings.cfg` — настройки интерфейса, введённые вручную курсы валют и последние
  значения расходов и накоплений в моделировании покупки.

Запись атомарная: временный файл проверяется чтением и только потом заменяет основной.
Если основной файл повреждён, данные берутся из резервной копии. Если повреждены оба,
файл переименовывается в `timeprice_data.corrupted_<время>.json`, приложение запускается
с чистыми данными и показывает уведомление.

## Запуск

1. Установите Godot 4.3 или новее (стандартная сборка, не .NET).
2. Откройте `timeprice/project.godot` в редакторе. Первое открытие импортирует
   ресурсы и построит кэш классов `class_name`.
3. Нажмите F5. Окно 400×860 имитирует телефон, Esc работает как «Назад».

### Тесты

```bash
# один раз: импорт проекта (создаёт .godot/ с кэшем глобальных классов)
godot --headless --path timeprice --import
# запуск тестов (код возврата 0 — успех)
godot --headless --path timeprice --script res://tests/test_runner.gd
```

### Сквозная проверка интерфейса

Проходит onboarding и все разделы, проверяет «Назад», сохранение, перезапуск и
восстановление повреждённого файла, сохраняет скриншоты в `user://smoke_shots/`.
**Сбрасывает данные приложения на этом компьютере.**

```bash
godot --path timeprice --resolution 800x1720 res://tests/ui_smoke/ui_smoke.tscn
```

Проверено в Godot 4.3: 105 модульных тестов и сквозная проверка — без ошибок.

## Android-сборка

1. В редакторе: «Редактор → Настройки редактора → Экспорт → Android» — укажите
   Android SDK и Java SDK (JDK 17). Debug keystore создаётся автоматически.
2. «Редактор → Управление шаблонами экспорта» — скачайте шаблоны для своей версии Godot.
3. «Проект → Экспорт → Android» (пресет уже настроен: `kz.timeprice.app`, портретная
   ориентация, arm64-v8a и armeabi-v7a, без разрешений, тесты исключены).
4. Сборка из командной строки:
   ```bash
   godot --headless --path timeprice --export-debug "Android" build/android/timeprice-debug.apk
   adb install -r timeprice/build/android/timeprice-debug.apk
   ```
5. Для Google Play нужны релизный keystore (`keystore/release*` в пресете) и формат AAB
   (`gradle_build/use_gradle_build=true`, `gradle_build/export_format=1`).
