# Переводы

Первая версия TIMEPRICE полностью на русском, переводов пока нет.

Как устроена локализация:

- Русские строки интерфейса служат ключами для `TranslationServer`.
- `Label`, `Button` и другие Control-узлы переводят текст автоматически
  (`auto_translate_mode` по умолчанию включён).
- Строки, которые собираются из шаблонов, проходят через `Loc.t()` и `Loc.tf()`
  (`scripts/core/loc.gd`). Формы множественного числа выбирает `Loc.plural()`.
- Язык хранится в `SettingsManager.locale` и применяется через `TranslationServer.set_locale()`.

Чтобы добавить язык (kk, uz, en):

1. Создать `data/translations/timeprice.csv` в формате Godot:
   первая колонка `keys` — русская строка, затем колонки `kk`, `uz`, `en`.
2. Импортировать CSV в редакторе и добавить полученные `.translation` в
   «Проект → Настройки проекта → Локализация → Переводы».
3. Добавить код языка в `SettingsManager.SUPPORTED_LOCALES` и правила
   множественного числа в `Loc.plural()`.
4. Добавить выбор языка в экран настроек.
