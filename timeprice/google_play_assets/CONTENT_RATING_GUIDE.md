# Анкета возрастного рейтинга (IARC)

Анкета заполняется в Play Console: «Политика → Контент приложения → Возрастные
ограничения». Ниже — ответы по фактическому содержанию версии 1.0.0. Формулировки вопросов
в консоли могут отличаться — отвечайте по сути.

**Категория приложения:** «Утилиты, продуктивность, коммуникации и другое» (не игра, не
социальная сеть, не развлечения).

| Тема вопроса | Ответ | Почему |
|---|---|---|
| Насилие, кровь, страх | Нет | |
| Сексуальный контент, нагота | Нет | |
| Грубая лексика | Нет | |
| Наркотики, алкоголь, табак | Нет | Привычки упоминаются только как траты (кофе, такси) |
| Азартные игры, имитация азартных игр | Нет | Нет ставок, лотерей, лутбоксов |
| Общение пользователей между собой, чаты, контент от пользователей, который видят другие | Нет | Приложение офлайн, данные видит только владелец |
| Передача местоположения другим пользователям | Нет | |
| Покупка цифровых товаров | Нет | Покупок в приложении нет |
| Ненавистнические высказывания, дискриминация | Нет | |
| Доступ к интернету без ограничений | Нет | Разрешения INTERNET нет |

**Ожидаемый результат:** самая низкая категория (3+ / PEGI 3 / «Для всех»). Возрастной
рейтинг и целевая аудитория — разные вещи: аудиторию 18+ вы указываете отдельно в разделе
«Целевая аудитория и контент».

Если в будущем появятся покупки, реклама или общение пользователей, анкету нужно пройти
заново.
